# Token Companion for Windows — Portable Edition (v0.4.20)

1. Extract this ZIP / executable to any folder.
2. Run `Token Companion (Client) 0.4.20.exe`.
3. The app tracks only local Codex, Claude Code, Antigravity, and IntelliJ activity on your PC.

No account, API key, or shared data is needed. Each person has their own companion and Pokédex.

Windows may show a SmartScreen warning because this community build is not code-signed. Only choose **More info → Run anyway** if you trust the person who sent you this executable.

### Features
- **Always ready**: Open the tray menu and enable **Launch at Windows sign-in** for automatic background startup.
- **Language**: Switch between English and 中文 in the top-right settings.
- **Auto-Update & LAN Sync**: The client will automatically detect your team's Master node when open on the local network to receive updates and connect for trades and battles.
